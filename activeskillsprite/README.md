# Active Skill sprites

Active Skill pages use the source `Sprite` field, not the skill name, because multiple skills can intentionally share one icon.

Sprite path:

`activeskillsprite/<Sprite>.png`

Examples from the source data include `Strike.png`, `DoubleSlash.png`, `Healing.png`, and `ThunderStruck.png`.

Missing sprite files are hidden automatically by the wiki UI.
