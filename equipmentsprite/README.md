# Equipment sprites

Equipment images are mapped directly from the stable `EquipmentKey`.

Upload PNG files to this folder using the exact EquipmentKey as the filename.

Examples:

- `Iron Sword.png`
- `Silver Armor.png`
- `Ring of Mermaid.png`

The wiki requests `equipmentsprite/<EquipmentKey>.png`. Missing images remain hidden until the correctly named PNG is uploaded.
