# Monster sprites

Upload monster sprites to this folder as PNG files using the exact `MonsterKey` / English source name as the filename.

Examples:

- `Slime.png`
- `Fire Slime.png`
- `King Slime.png`
- `Goblin Archer.png`

The wiki automatically requests `monstersprite/<MonsterKey>.png` for both monster cards and monster detail pages. Spaces and other URL characters are encoded automatically by the wiki code.

If a sprite has not been uploaded yet, the broken image is hidden automatically and the monster card/detail page continues to render normally.
